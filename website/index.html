怎么搬

三步，第二步你最熟

界面只有两个按钮：Claude 和 ChatGPT。选好以后，导出还是导入，再挑个位置，剩下的自动完成。导入时会一步步引导你选一个新文件夹。

1

在旧电脑上导出

点 Claude 或 ChatGPT，选"导出"，挑一个保存位置。几秒到一分钟，得到一个 .zip。

Claude-聊天记录-旧电脑-20261023.zip
2

把文件拷过去

U 盘、网盘、微信传文件、局域网共享，用什么都行。

180 MB → 新电脑桌面
3

在新电脑上导入

选"导入"，点那个 .zip，再选一个新文件夹。对话用到的所有文件都放进这个文件夹，重新打开 Claude 或 Codex 就能接着用。

D:\Claude 对话迁移\my-app\…

放心的地方

搬家不丢东西

不联网

没有账号，没有服务器。记录只在你的电脑和你选的文件之间移动。

不碰你原有的文件

所有内容放进你新选的文件夹，这台电脑上原有的东西不会被改动；同名文件内容不同时，两份都留着。

列表原样回来

Claude 的会话列表、Codex 的项目分组和改过的标题，都按旧电脑的样子登记好，路径自动指向新文件夹。

正在聊的不打扰

10 分钟内还在写入的对话不会被覆盖；导入 Codex 记录前会提醒你先把 Codex 关掉。

常见问题

搬之前你可能想问

为什么 Codex 的记录动辄几个 GB？

记录里大约九成的体积是图片。浏览器截图、电脑操作截图这些都以 base64 文本直接存在会话文件里，而且同一张截图常被记录不止一次。真正的文字对话只占一小部分。压缩包几乎不会变小，因为图片本来就压缩过。

导入以后还要做什么？

Claude：完全退出（包括右下角托盘图标）再重新打开，导入的对话就在列表里。Codex：导入时会自动登记，打开就能看到。项目里如果用到依赖（node_modules、.venv），需要在新文件夹里重新安装一次。

项目原来分散在不同的盘，搬过来放在哪？

都放进导入时你选的那个文件夹，每个项目一个子文件夹，比如 D:\Claude 对话迁移\my-app。对话会自动指向新位置，不用管旧电脑上是什么路径。只有项目里写死的旧绝对路径需要自己改一下。

AI 存到桌面或别的文件夹的文件也会搬吗？

会。AI 用写文件工具保存到工作文件夹外面的文件（比如导出到桌面的视频、报告），会从聊天记录里找出来，放进新文件夹的「其他产出文件」里。由脚本间接生成、记录里没写路径的文件找不到，需要自己拷。

导入 Codex 时提示"请先退出 Codex"？

导入时要把对话登记进 Codex 的列表，需要 Codex 完全退出。把 Codex 桌面版（包括托盘图标）和 VS Code 里的 Codex 插件都关掉，点"我已退出，重试"即可，不用重新选文件。

会把我的登录信息一起带走吗？

不会。auth.json、secrets/、凭证和设置都不在打包范围内。新电脑上需要自己登录一次。

支持 Mac 吗？

目前只有 Windows 版。
