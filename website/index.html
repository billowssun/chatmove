放心的地方

搬家不丢东西

不联网

没有账号，没有服务器。记录只在你的电脑和你选的文件之间移动。

不删、不乱覆盖

导入是合并：新对话直接加进来，已有的对话只在压缩包里那份更完整时才更新，旧文件先备份。

Codex 标题跟着走

Codex 的对话列表和改过的标题存在它自己的数据库里。导入后会让 Codex 自己重新扫描，把标题恢复回来。

正在聊的不打扰

10 分钟内还在写入的对话不会被覆盖；导入 Codex 记录前会提醒你先把 Codex 关掉。

常见问题

搬之前你可能想问

为什么 Codex 的记录动辄几个 GB？

记录里大约九成的体积是图片。浏览器截图、电脑操作截图这些都以 base64 文本直接存在会话文件里，而且同一张截图常被记录不止一次。真正的文字对话只占一小部分。压缩包几乎不会变小，因为图片本来就压缩过。

导入后 Claude 桌面版侧边栏里看不到？

Claude 桌面版的侧边栏由它自己的一份会话清单驱动，这一版还不会写入那份清单。对话本身已经在了：在终端里进入同一个项目文件夹，运行 claude --resume 就能找到并接着聊。

两台电脑上的项目路径不一样怎么办？

Claude Code 按项目的完整路径归类对话。旧电脑上是 D:\projects\my-app，新电脑上也放在同样的路径最省事。路径不同的话，对话仍会被导入，只是要在原路径下才能续聊；命令行版 chatsync 支持路径映射。

导入 Codex 时提示"请先退出 Codex"？

Codex 开着时会锁住自己的列表。把 Codex 桌面版和 VS Code 里的 Codex 插件都关掉，点"我已退出，重试"即可，不用重新选文件。

会把我的登录信息一起带走吗？

不会。auth.json、secrets/、凭证和设置都不在打包范围内。新电脑上需要自己登录一次。

支持 Mac 吗？

目前只有 Windows 版。
